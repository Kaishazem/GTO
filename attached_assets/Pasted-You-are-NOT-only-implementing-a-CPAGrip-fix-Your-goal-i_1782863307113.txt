========================

2. CPAGrip Adapter

For CPAGrip specifically:

The outgoing offer URL should use:

tracking_id=userId|taskId

NOT s1/s2 anymore.

When a postback arrives:

tracking_id=userId|taskId

should automatically be split into:

userId

taskId

If s1+s2 exist instead, support them for backward compatibility.

========================

3. GET / POST

CPAGrip sends GET.

Some networks send POST.

The engine should support BOTH without duplicating business logic.

The business logic should exist only once.

========================

4. Platform Detection

The backend should not require a mandatory platform parameter.

If the platform is detectable automatically, detect it.

If not, use a small adapter/config.

Do NOT reject conversions because platform is missing.

========================

5. Architecture

Universal Parser

Platform Adapter

↓

Normalized Conversion Object
