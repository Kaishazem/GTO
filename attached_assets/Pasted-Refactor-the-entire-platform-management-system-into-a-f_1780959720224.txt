Refactor the entire platform management system into a fully dynamic and scalable architecture.

IMPORTANT:

This project already contains working fixes for:

- withdrawals
- reconciliation
- manual task earnings
- withdrawal approval
- wallet settlement

DO NOT modify these systems.

Your task is ONLY to redesign the platform management and importing architecture while preserving all existing business logic.

Goal

The admin must be able to manage ANY advertising network entirely from the Admin Panel without changing the source code.

The system should support unlimited future platforms.

---

Part 1 — Dynamic Platform Management

Replace the current platform configuration with a fully dynamic management system.

The admin should be able to:

✅ Add Platform

✅ Edit Platform

✅ Delete Platform

✅ Enable / Disable Platform

✅ Test Connection

✅ Run Manual Import

✅ View Last Import Status

✅ View Last Error

✅ View Imported Offers Count

Deleting a platform should:

- remove it from the platform list
- stop scheduled imports
- never delete imported tasks automatically
- never affect wallet, withdrawals or reconciliation

Disabling a platform should:

- stop automatic imports
- preserve all imported tasks
- preserve reporting history

Part 3 — Universal Import Architecture

Completely refactor api/import-platform.js.

Requirements:

There must be NO:

if(platform==="adgem")

if(platform==="lootably")

switch(platform)

The importer must become platform-agnostic.

Read everything dynamically from Firestore.

Support:

- Bearer Token
- API Key Header
- Query Parameter Authentication
- Basic Authentication
- Custom Headers

Support different API response structures dynamically.

Examples:

offers

data

results

campaigns

items

Support configurable mapping for:

- id
- title
- description
- payout
- url
- image
- countries
- devices
- category

without modifying code.

Part 4 — Firestore

Improve Firestore performance.

Avoid sequential writes.

Use batching or Promise.all where appropriate.

Keep duplicate detection using externalId.

Use the proper Firestore API.

Never duplicate platform secrets inside task documents.

Secrets must remain only inside platform documents.
