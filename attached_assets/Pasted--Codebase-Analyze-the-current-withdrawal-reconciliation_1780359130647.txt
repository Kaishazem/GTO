@Codebase

Analyze the current withdrawal reconciliation logic.

Current bug:

Withdrawal approval is being blocked because reconciliation is considering rejected tasks, pending tasks, and/or manual tasks.

This is incorrect.

==================================================
EXPECTED BUSINESS LOGIC

The platform has two task types:

1. manual
2. platform

==================================================
WALLET LOGIC (KEEP CURRENT BEHAVIOR)

Approved task:

- remove reward from pending balance
- add reward to available balance

Rejected task:

- remove reward from pending balance
- do NOT add reward to available balance

This behavior already exists and should remain unchanged.

==================================================
RECONCILIATION LOGIC

Reconciliation must ONLY consider approved platform earnings.

The following task statuses must be COMPLETELY IGNORED:

- pending
- rejected
- cancelled
- expired

Only:

status = "approved"

should participate in reconciliation calculations.

==================================================
PENDING TASKS

Pending tasks must NOT block withdrawals.

Pending tasks are unresolved earnings and are already stored in pending balance.

They are not withdrawable, but they must not reduce reconciliation percentage.

==================================================
REJECTED TASKS

Rejected tasks must NOT block withdrawals.

Rejected tasks have already been removed from pending balance and are not valid earnings.

They must be completely ignored during reconciliation.

==================================================
MANUAL TASKS

Manual task earnings are valid withdrawable earnings.

When a manual task is approved:

- reward moves to available balance
- user can withdraw those earnings

However:

- manual tasks must NOT participate in platform reconciliation
- manual tasks must NOT reduce reconciliation percentage
- manual tasks must NOT block withdrawal approval
- manual tasks do NOT require platform reports

A user must be able to withdraw approved manual-task earnings even when no platform report exists.

==================================================
PLATFORM TASKS

Platform tasks participate in reconciliation.

Only APPROVED platform earnings should be compared against platform reports.

==================================================

Withdrawal approval should be ALLOWED because available earnings are valid.
